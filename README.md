# linuxhardening
Script de endurecimiento de seguridad para sistemas Ubuntu/Debian que aplica buenas prácticas defensivas sin riesgo de dejarte fuera del servidor ni parar servicios en producción.  A diferencia de muchos scripts de “hardening agresivo”, éste está diseñado para entornos reales (VPS, servidores en producción, máquinas remotas sin acceso físico).
